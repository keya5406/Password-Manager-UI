
# Password Manager UI

A modern frontend application for securely managing and storing passwords.

## Overview

This is a React-based web application built with Tailwind CSS that provides a user-friendly interface for password management. All credentials are encrypted using AES-ECB encryption before storage.

## Features

- 🔐 Secure password storage with AES-ECB encryption
- 🎨 Clean and intuitive UI built with Tailwind CSS
- ⚡ Fast and responsive React application
- 🔑 Manage multiple credentials efficiently


## Tech Stack

- **Frontend Framework**: React.js
- **Styling**: Tailwind CSS
- **Encryption**: AES-ECB
